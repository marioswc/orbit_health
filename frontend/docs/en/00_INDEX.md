# Frontend Documentation by Module — ORBIT Health

A clear, jargon-free guide to what the **ORBIT Health** frontend does, how it is organized, and how each part of the user experience was solved.

---

## Documented Modules & Layers

| Document | What it covers |
|---|---|
| [01 — Monitor & Environments](./01_MONITOR_AND_ENVIRONMENTS.md) | Main health dashboard, interactive body zones, vital signs, gravity environments (Earth/Orbit/Moon/Mars), NASA-sourced explanations, and measurement streaks. |
| [02 — Wristband & Simulation](./02_BAND_AND_SIMULATION.md) | Interactive 3D wristband view, automatic sensor/simulator flow, removal of manual entry from the main UI, and transparent `simulado` data labeling. |
| [03 — Assistant & Local AI / Voice](./03_ASSISTANT_AND_LOCAL_VOICE.md) | Dedicated Assistant tab, offline clinical summary explanations, tone/detail preferences, and floating push-to-talk voice bubble. |
| [04 — Wellbeing & Privacy](./04_WELLBEING_AND_PRIVACY.md) | Daily mood check-in, private personal journal, PHQ-2 screening, crisis protocol, and revocable consent notices for the onboard physician. |
| [05 — Link, History & Earth View](./05_LINK_HISTORY_AND_EARTH.md) | Communication blackout handling, live mission simulator, Earth-received reports, and collapsible paginated measurement history. |
| [06 — Navigation, Styling, i18n & PWA](./06_NAVIGATION_STYLE_I18N_AND_PWA.md) | Animated sidebar, new silhouette logo, ES/EN language switching, light/dark themes, startup performance, and minimal offline PWA support. |
